❓ TROUBLESHOOTING

ISSUE: Port 3000 already in use
  SOLUTION: npm run dev -- -p 3001

ISSUE: npm install fails
  SOLUTION: Delete node_modules and package-lock.json, then npm install again

ISSUE: Styles not appearing
  SOLUTION: Restart dev server, clear browser cache (Ctrl+Shift+Del)

ISSUE: Hamburger menu not working
  SOLUTION: Check Navbar.js useState import and mobile menu logic

ISSUE: Links not working
  SOLUTION: Verify href attributes in components
